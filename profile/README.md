## Proyectos

> El código fuente, la documentación técnica y los entornos de los sistemas son **privados y confidenciales**.
> Aquí solo se describe el alcance general de cada uno.

### Administración y Recursos Humanos

Plataforma **web y móvil** para la gestión administrativa y de personal, con un módulo de
**análisis predictivo** para apoyar la toma de decisiones.

**Stack:** React · Node.js + Express · PostgreSQL · Docker · React Native + Expo

### Gestión de Proyectos de Ingeniería

Sistema web para dar **seguimiento a proyectos** de principio a fin: planificación, avance,
alertas y comunicación del estado con los clientes.

**Stack:** Django · React + Vite + Tailwind · PostgreSQL

### Gestión de Laboratorio

Sistema web para la **operación del laboratorio**: registro de muestras, ensayos, programación
e informes.

**Stack:** Django + Django REST Framework · React + Vite · PostgreSQL

## Cómo trabajamos

- Ramas `feature/*` y `fix/*` → **pull request a `develop`** → `main` para cada versión.
- Cada PR pasa por **revisión** y por **integración continua** (lint, pruebas y build) antes de entrar.
- Commits con [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`…).
- Código con nombres claros; **todo lo que ve el usuario, en español**.
